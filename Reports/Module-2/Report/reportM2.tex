\section{IKEv1 with Digital Signatures}

\subsection{Introduction}

This report describes the configuration and analysis of IPSec VPN using IKEv1 with digital certificates (PKI-based authentication using SCEP). 
The objective is to replace pre-shared keys with RSA signatures issued by a Certification Authority (CA).

\subsection{Network Setup}

The topology consists of routers R1, R2 and RA (Certification Authority). RA also provides NTP synchronization and PKI services.

\subsection{PKI Installation Verification}

The following IOS commands confirm successful installation of CA and router certificates:

\begin{itemize}
\item \texttt{show crypto pki certificates}
\item \texttt{show crypto ca certificate}
\item \texttt{show crypto key mypub rsa}
\end{itemize}

Both R1 and R2 successfully enrolled with the CA and obtained signed X.509 certificates via SCEP. The corresponding RSA public keys were generated locally and included in the certificate exchange process.

\subsection{SCEP Enrollment Analysis}

SCEP (Simple Certificate Enrollment Protocol) is used to automate certificate distribution between routers and the CA using HTTP.

The enrollment process consists of:

\begin{itemize}
\item \texttt{CA certificate request}
\item \texttt{CA certificate response}
\item \texttt{Router certificate request}
\item \texttt{Router certificate issuance}
\end{itemize}

The captured HTTP messages show certificate exchange between R1 and the CA. The content-type field indicates certificate payload transfer (.crt).
